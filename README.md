# ファイアーシックス

ブラウザで遊べるバレーボールRPG（6対6／1セット10点先取）。

## 遊び方
- このフォルダをHTTPサーバーで配信して `index.html` を開いてください（file:// ではデータ読み込みができません）。
  例：`python3 -m http.server 8000` → http://localhost:8000/
- `index.html` が Phaser 版（本体）、`core.html` は Canvas 版（v1.0.3）です。セーブデータは共通です。

## 操作
- 矢印キー：移動
- Z：決定／話す、カットイン送り
- X：プロフィール
- L：選手ライブラリ／編成
- F：スカウト候補の絞り込み切替

## 内容
- 選手250人、必殺技600、ストーリー本編8試合＋クリア後ルート16試合
- 必殺技カットイン：主要キャラは本人イラスト、その他は属性別イラスト
